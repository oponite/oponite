# Welcome to my profile!

Tl;dr: I build systems for understanding complex systems.

I like problems where the machinery is messy, the information is incomplete, and the existing abstractions aren't quite good enough. Sometimes that means tracing an institutional trade through brokers, matching systems, allocations, databases, and portfolio infrastructure. Sometimes it means digging through application code and production data to figure out why a financial system is behaving strangely. 

At other times, [it means building an entirely new programming language because I don't like how existing software represents uncertainty](https://github.com/oponite/lana). 

My domain coverage: **computer science, financial markets, information theory, and systems design**.
