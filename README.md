# Welcome to my profile!

I built an entire programming language because I wasn't satisfied with how existing software represents uncertainty.

It's called [Lana](https://github.com/oponite/lana), and it's an exploration of what programming looks like when uncertainty, information, and decision-making become first-class computational concepts. That means designing the language, its mathematical foundations, compiler, virtual machine, and execution model from the ground up.

I'm drawn to problems where existing abstractions aren't quite good enough. Sometimes that means tracing institutional trades through interconnected processes, actors, and applications. Sometimes it means investigating production systems to understand why software behaves unexpectedly. And sometimes it means questioning the foundations of computation itself.

In a nutshell, **I build systems to understand complex systems**.

## Work

- **[Lana](https://github.com/oponite/lana):** An independently developed programming language for uncertainty-aware computation and auditable decision-making. Start with [Can uncertainty be programmable?](https://oponite.github.io/data-articles/website/can-uncertainty-be-programmable.html)
- **[Living Canvas](https://oponite.github.io/living-canvas/):** a browser-based live canvas that responds as you paint, powered by the Lana WebAssembly engine.
