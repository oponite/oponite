# Welcome to my profile!

I build systems for understanding complex systems.

I like problems where the software is messy, information is unclear, and existing abstractions aren't quite good enough. Sometimes that means tracing an institutional trade through its processes, actors, and connectors. Sometimes it means digging through application code and production data to figure out why a system is behaving strangely.

And sometimes it means [building an entirely new programming language](https://github.com/oponite/lana) because I don't like how existing software represents uncertainty.

## Work

- **[Lana](https://github.com/oponite/lana):** a programming language for uncertainty-aware computation and auditable decision-making. Start with [Can uncertainty be programmable?](https://oponite.github.io/data-articles/website/can-uncertainty-be-programmable.html)
- **[Living Canvas](https://oponite.github.io/living-canvas/):** a browser-based drawing simulation that responds as you paint, powered by a Lana WebAssembly engine.
- **[Epistemia](https://oponite.github.io/epistemia/):** my research archive of papers, technical reports, and exploratory notes.
- **[Qualcomm AI Hub MCP](httalcomm-ai-hub-mcp):** anunofficial MCP server for compiling, profiling, and running AI models on hosted devices.
