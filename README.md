# Welcome to my profile!

Tl;dr: I build systems for understanding complex systems.

I like problems where the software is messy, information is lacking clarity, and existing abstractions aren't quite good enough. Sometimes that means tracing an institutional trade through its processes, actors, and connectors. Sometimes it means digging through application code and production data to figure out why a system is behaving strangely.

At other times, [it means building an entirely new programming language because I don't like how existing software represents uncertainty](https://github.com/oponite/lana). 

My domain coverage: **computer science (formal methods, compilers), financial markets, information theory, decision theory, systems architecture**.
